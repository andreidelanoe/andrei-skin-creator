Mode d'emploi
  • Choisis une partie, une couche, puis une face (ou clique sur le patron miniature). Tu peux aussi double-cliquer sur le modèle 3D pour aller à la face visée.
  • Les pixels jamais peints apparaissent en blanc (avec un petit point dans l'éditeur). À l'export, ils restent blancs sur la couche de base et transparents sur la seconde couche.
  • La seconde couche flotte un demi-pixel au-dessus du corps : cheveux qui dépassent, capuche, lunettes, relief de nez ou d'oreilles. Elle ne peut pas aller plus loin : un vrai volume qui ressort sur plusieurs pixels n'existe pas dans les skins standards.
  • Clic droit ou Alt + clic : pipette. Ctrl+Z / Ctrl+Y : annuler / rétablir. Glisser-déposer un PNG sur la page pour l'importer.
  • « Patron entier » affiche le fichier 64×64 tel qu'il sera exporté.
  • Ton travail est sauvegardé automatiquement dans ce navigateur.
